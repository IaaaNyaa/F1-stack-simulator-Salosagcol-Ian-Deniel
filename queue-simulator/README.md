Queue Data Structure Simulator

A Flask application that demonstrates a First In, First Out (FIFO) queue.

Run locally:

1. Install the dependencies with `pip install -r requirements.txt`.
2. Start the app with `python app.py`.
3. Open `http://127.0.0.1:5000` in a browser.

Use Enqueue to add an item at the rear, Dequeue to remove the front item,
Peek to highlight the front item without removing it, and Clear to empty
the queue and its dequeued-item history.
